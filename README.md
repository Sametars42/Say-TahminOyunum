# Say-TahminOyunum
C# programlama dili kullanılarak konsol (CMD) ortamında geliştirilen bu projem; farklı zorluk seviyeleri, anlık ipucu yönlendirmeleri ve performans sayacı içeren etkileşimli bir sayı tahmin otomasyonudur.

Seviye / Zorluk Seçim Menüsü: Kullanıcının isteğine göre 4 farklı sayı aralığından (1-10, 1-100, 1-500, 1-1000) birini seçebildiği dinamik menü yapısı.  
Akıllı İpucu Sistemi: Kullanıcının girdiği değere göre anlık olarak "tahminin Küçük!" veya "tahminin Büyük!" şeklinde yönlendirme yapılması.  
Performans ve Skor Sayacı: Oyuncunun doğru sonuca kaçıncı tahminde ulaştığını hesaplayan ve tebrik mesajı sunan sayaç algoritmaları ("5 defa tahmin ederek oyunu kazandın!").  
Sürekli Oyun Döngüsü: Oyun bittiğinde kullanıcıyı tekrar zorluk seçim ekranına yönlendiren ve çıkış seçeneği (x) sunan kesintisiz akış yönetimi.  

Kullanılan Teknolojiler
Programlama Dili: C# (.NET Core / .NET Framework)
Çalışma Ortamı: Konsol / Komut Satırı (CMD)
Yazılım Prensipleri: Random Sınıfı Kullanımı, switch-case Kontrol Yapıları, while/do-while Döngüleri, Konsol UI Biçimlendirme
